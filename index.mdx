Reflect is an open-source, local-first note-taking app for Mac and iPhone. Notes live as plain Markdown files in a folder you own — no proprietary database, no cloud lock-in. The app opens to today's daily note, lets `[[wiki links]]` weave your ideas together, and brings optional AI features powered by your own API keys.

## Get started in minutes

<Steps>
  <Step title="Download and install">
    Grab the latest Mac release — Apple silicon or Universal — from GitHub Releases. For iOS, join the TestFlight beta. No Reflect account required.
  </Step>
  <Step title="Create or open a graph">
    On first launch Reflect asks you to create a **graph** — a plain folder on disk. Pick a location (or an iCloud Drive folder for instant multi-device sync) and start writing.
  </Step>
  <Step title="Write in today's note">
    The app always opens to today's daily note. Type `[[` to create a wiki link to another note, `⌘K` to search across your graph, and `⌘J` to ask AI questions about your notes.
  </Step>
  <Step title="Back up your notes">
    Connect GitHub in Settings → Backup for versioned git history, or keep your graph inside an iCloud Drive folder for seamless Apple-device sync.
  </Step>
</Steps>

## Why Reflect?

<CardGroup cols={3}>
  <Card title="Plain Markdown files" icon="file-lines">
    Notes are `.md` files you can read, edit, back up, and diff with any tool — forever.
  </Card>
  <Card title="No Reflect account" icon="user-slash">
    The app works entirely offline. External services connect only after you configure them.
  </Card>
  <Card title="BYOK AI" icon="brain">
    AI queries go directly to OpenAI, Anthropic, Google, or OpenRouter using your own API keys. Reflect never proxies your data.
  </Card>
  <Card title="Privacy first" icon="lock">
    Add `private: true` to any note's frontmatter and its content is hard-blocked from every external service.
  </Card>
  <Card title="Scripting & agents" icon="terminal">
    The bundled `reflect` CLI lets scripts and AI agents search notes, read today's daily, and resolve note paths — all read-only and JSON-friendly.
  </Card>
  <Card title="MIT open source" icon="code-branch">
    The full app — desktop shell, editor, indexing, sync, CLI — is open source under the MIT license.
  </Card>
</CardGroup>
